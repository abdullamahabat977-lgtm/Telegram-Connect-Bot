Random Connect — Telegram Random Chat Bot

موخه
Random Connect د ټیلیګرام کاروونکي د خپلې خوښې ژبې او هېواد له مخې د تصادفي خبرو لپاره نښلوي.

اوسنی پړاو
- د ژبې انتخاب: پښتو، دري، English، اردو او عربي.
- د هېواد انتخاب او د کارن په حساب کې یې ساتل.
- د ژبې او هېواد د بدلولو تڼۍ.
- یوازې د موجود message handler کارول؛ نوی event handler نه اضافه کېږي.

د راتلونکو پړاوونو امکانات
- د ژبې او هېواد له مخې د تصادفي ملګري موندل.
- د دوو کسانو ترمنځ د پیغامونو لېږد.
- بل ملګری موندل او خبرې بندول.
- د ناوړه چلند راپور ورکول او بلاک کول.

د فایلونو ځای
- tgcloud/schema.js — د ډیټابېس جدولونه.
- tgcloud/handlers/message.js — د موجود message handler لپاره کوډ.

مهم
د schema بدلولو وروسته د Serverless د Database برخې کې د بدلونونو کتنه ضروري ده. که زاړه جدولونه د حذف کېدو په توګه ښکاره شي، تر کتنې مخکې د حذف تایید مه کوئ. د GitHub بدلونونه په اتومات ډول د بوټ ژوندی کوډ نه بدلوي؛ کوډ باید په اړوند موجود Serverless handler کې هم ځای پر ځای او وازمویل شي.
